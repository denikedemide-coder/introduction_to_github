What is Git: Git is a free and open source distributed version control system designed to handle everything from small to very large projects with speed and efficiency
What is GitHub: GitHub is a web-based Git repository hosting service, which offers all of the distributed revision control and source code management (SCM) functionality of Git as well as adding its own features.
What is the difference between Git and GitHub: Git is the tool; GitHub is the online platform.
How to create a repository: 1. GitHub → Profile Picture → Repository → New repository → name it → Add Description → Create.
What is a README: You can add a README file to a repository to communicate important information about your project. A README, along with a repository license, citation file, contribution guidelines, and a code of conduct, communicates expectations for your project and helps you manage contributions.
How to write good READMEs: A README is your project’s first impression — it’s the front door to your code and can make or break interest from users and contributor. A great README answers three questions fast: what it does, why it matters, and how to use it 
How to commit: You do:
git add .
git commit -m ("Anything you want to put here.")
How to write helpful commit messages: Commit message keywords help categorize changes, improve collaboration, and enable automated tools to generate changelogs or manage versioning. The Conventional Commits specification is a widely adopted standard for this purpose.
How to push code: After you have done commit you do
git push
